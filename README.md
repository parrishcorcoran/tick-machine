# tick-machine

GPT-2 as notes on a circle: every weight a 12-bit angle with a lap counter, every neuron a pile
that superposes what lands on it, every layer one circular convolution, the whole model 49 turns
and 49 stops. Identical tokens to fp32 GPT-2 on every prompt tried, measured on a MacBook Air.

Start with **[WRITEUP.md](WRITEUP.md)** — the whole path step by step, with the program and the
number for each step. **[NOTES.md](NOTES.md)** has every measurement in order.
**[HRR_MAP.md](HRR_MAP.md)** maps the transformer's operations to HRR's, from the papers.

Cleanest statement of the model: `python3 -u turns_dial.py --case 0 --n 2`
Cleanest picture of it moving: `python3 dial_flow_order.py --T 16 --stream dial --input step`

Needs: Python 3.9+, torch, transformers (GPT-2 weights download on first run), numpy.
The exported dial files in `gpt2_dial/` are regenerated by `edge_model.py`; `reference.json`
(the fp32 greedy reference) is included.
